# Showcase Fleet releases

Signed packages for Showcase Fleet, AD Group's manager for Showcase display-suite NUCs. NUCs install from here;
which version each NUC runs is set on the Showcase Fleet dashboard. Every file a NUC uses is checked against
`catalogue.json`, signed with AD Group's key (`fleet_public_key.xml`). Nothing in this repo is secret.

Published by `publish_release.ps1`; don't edit by hand. Catalogue 2, 23 Nov 2026.
